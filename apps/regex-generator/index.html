Good to know

  • Blocks run in order. Each block matches the next piece of text. Use How many to say a piece repeats or is optional.
  • Groups keep blocks together, so they can repeat as one unit. A capture group also remembers what it matched, so you can use it later (with Same text as a group) or read it in your code.
  • Followed by / preceded by checks what's next to the match without making it part of the match. For example: a number, only if preceded by “$”.
  • As few as possible (lazy) stops a repeat at the first chance, which matters with “any character”: in "a" and "b", quoted text with as few as possible finds "a" and "b" separately instead of one long match.
  • Never give back (possessive, atomic) makes a repeat keep everything it took. It's for speed in big texts; most patterns don't need it.
  • Languages differ. The regex is written for the language you pick, and the notes under it say what that language can't do. The test box runs the JavaScript version in your browser.
  • Nothing you type leaves your browser.
