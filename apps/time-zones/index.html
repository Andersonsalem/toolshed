          Good to know

          • Times come from your browser's own time zone database, so the page works offline. Daylight saving changes are handled for the date you pick; when one is close, the page tells you.
          • Public holidays aren't included: check them for each country before you send an invite.
          • The calendar file stores the time in UTC, so every calendar app shows it in each person's own time.
          • Your list of places is saved in this browser only. A shared link contains the places, date and time, nothing else.
