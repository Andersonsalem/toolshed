QR Code Generator

QR codes for links, Wi-Fi, contacts, emails, calls and texts. Everything is inside the code itself, so it never expires and nobody tracks who scans it.

Style and size

Higher means the code still scans when scratched or partly covered, but it gets denser. Medium suits most uses; choose High for codes that will get worn, like stickers outdoors.

For posters and anything that gets resized, SVG stays sharp at every size.

    Good to know
    
      
      
        
    • These codes never stop working. Many "free" QR sites make codes that point to their own server and then redirect, so they can count scans, and the codes stop working if you don't pay. Codes made here hold your link or details directly.
      • 
        
    • That also means you can't change where a code points after printing it. If the link might change, point it at a page you control.
      • 
        
    • Test before you print. Scan the code with a couple of phones, from the distance people will use. A rule of thumb: the code should be at least a tenth as wide as the scanning distance (30 cm away → at least 3 cm wide).
      • 
        
    • Dark code on a light background scans best. Light-on-dark and low-contrast colors fail in many scanner apps.
      • 
        
    • Nothing you type is saved or sent anywhere. Only the style settings are remembered in this browser.
