Tensor Shape Visualizer

Paste PyTorch or NumPy code and see every tensor drawn, step by step: a bar, a grid, a cube, a row of cubes. Each dimension keeps its color as it moves, and shape errors are explained in plain words.

Your browser is blocking storage (this often happens in private windows), so your code won't be kept when you close this page.

Steps

How to read the drawings

  • 1D is a bar, 2D a grid (rows × columns), 3D a box: a stack of grids going back into the page. 4D is a row of boxes (one per entry of the first dimension, usually the batch) and 5D is rows of those. Beyond 5D, the last 5 dimensions are drawn.
  • The last dimension runs along the bottom edge, the one before it down the left edge, and the one before that along the edge going back. The numbers under boxes are their indices: box 2 is x[2].
  • A dimension keeps its color through every operation, so you can follow it through a permute or reshape. Merged dimensions get a joined name like C·H·W. Size-1 dimensions are grey.
  • Lengths grow with the logarithm of the size, so 1,024 still fits next to 3. Compare the numbers, not the lengths.
  • What feeds what? Click any cell of a drawing to trace that element (or focus a drawing and press Enter). Every drawing then shows, in violet, the elements that feed into it, and in dark grey, the later elements it feeds, through sums, matrix products, convolutions, pooling, normalization and the rest. Adjust the index in the bar at the top, or stop tracing there. Where a step picks elements by their values (index_select, gather, embeddings), the highlight covers every element that could be used, and the bar says so; if the tool doesn't know how an operation moves elements, the trace stops there and the bar names the line.
  • Where do the elements go? Under a step that moves elements around (reshape, flatten, permute, broadcasting, repeat, indexing, cat, stack, split…), pick a dimension to color by. Each element of the input gets the color of its index along that dimension, and the result shows where each one landed: after flatten the colors become bands, after permute they run along a new edge, and broadcast or repeated elements repeat their color. Uncolored parts come from another input. A box shows its front, top and side; the colors inside it are hidden. Above 24 cells along an edge (12 going back), each painted cell stands for a range of elements.

What it understands

Straight-line code, one statement after another: assignments, method chains, indexing and arithmetic. A whole nn.Module can be pasted: the class and def lines are skipped and self.layer works. Add a line that makes the input, like x = torch.randn(8, 3, 32, 32).

The full list of operations
Making tensors
torch: randn, rand, zeros, ones, empty, full, randint, randperm, arange, linspace, eye, tensor, from_numpy, *_like. NumPy: zeros, ones, empty, full, arange, linspace, eye, array, np.random (randn, rand, random, normal, uniform, randint, choice, permutation, default_rng).
Reshaping
reshape, view (with PyTorch's memory-layout rule), flatten, unflatten, ravel, squeeze, unsqueeze, expand_dims, permute, transpose, t, .T, .mT, swapaxes, movedim, moveaxis, expand, expand_as, broadcast_to, repeat, tile, repeat_interleave, np.repeat, contiguous, narrow, select.
Reductions
sum, mean, prod, std, var, max, min, amax, amin, argmax, argmin, median, any, all, logsumexp, norm, linalg.norm, cumsum, topk, sort; with dim / axis and keepdim / keepdims.
Joining and splitting
cat, concat, concatenate, stack, hstack, vstack, dstack, split, chunk, unbind, np.split, np.array_split.
Matrices
@, matmul (including 1D and batch broadcasting), mm, bmm, mv, dot, np.dot, outer, einsum (with ...), F.linear, linalg.inv, linalg.det.
Element by element
+ − * / // % **, comparisons, add, mul, maximum, where, masked_fill, and functions that keep the shape (exp, relu, sigmoid, softmax, clamp and many more), all with broadcasting.
Indexing
Numbers, slices with steps, None / np.newaxis, ..., and lists of indices (including several at once), gather, index_select.
Layers (torch.nn and F)
Linear, Conv1d/2d/3d (stride, padding, 'same', dilation, groups), ConvTranspose, MaxPool, AvgPool, AdaptiveAvgPool, Flatten, Unflatten, Embedding, BatchNorm, LayerNorm, GroupNorm, Upsample / interpolate, pad, PixelShuffle, Dropout, activations, Sequential, scaled_dot_product_attention, and losses (cross_entropy, mse_loss and others) with their shape checks.

Not covered, on purpose

Anything whose output size depends on the values: boolean masks (x[x > 0]), nonzero, unique. Recurrent and attention layers (nn.LSTM, nn.MultiheadAttention, Transformer layers), sparse and complex tensors, and data types. Loops and if statements: write each step on its own line.

How it works

  • It doesn't run Python. It reads your code and applies each operation's shape rule, written from the PyTorch 2 and NumPy 2 documentation. No numbers are computed, which is why it's instant even for huge tensors.
  • Where a library's own error message is known, it's quoted under the plain-English explanation, so you'll recognise it when you see it for real.
  • It covers the common operations, not all of them. If it says it doesn't know something, that's not a claim that it doesn't exist.
  • Your code stays in this browser and is saved there. Nothing is uploaded. “Copy link” puts the code in the link itself.
